05 / Frequently asked

A few things
worth knowing

What are tracking parameters?

They are values added to a URL, often in its query string, to help identify campaign sources or attribute visits. They are not always required to reach the page itself.

Does Votrixain remove every query parameter?

No. A query parameter can be part of how a page works. Votrixain is intended to remove recognized tracking parameters, not indiscriminately strip every query value.

Does cleaning a link change its destination?

The intended behavior is to retain the destination while removing recognized tracking information. Some websites rely on query values for functionality, which is why not every parameter should be removed.

Where can I review the implementation?

The public GitHub repository contains the extension source, documentation, tests, and current license information.
